# Real Time Data Fetching

## Introduction

Real Time Data Fetching is the process of collecting live data from online sources using APIs.

This project fetches real-time weather information using Python and API requests.

---

## Objectives

- To fetch real-time data using APIs
- To use Python requests library
- To display live weather information
- To understand API integration

---

## Tools Used

- Python
- Requests Library
- Google Colab
- API
- GitHub

---

## Steps Performed

1. Imported required libraries
2. Connected to Weather API
3. Fetched real-time weather data
4. Displayed temperature and wind speed
5. Converted data into table format

---

## Conclusion

Real-time weather data was fetched successfully using API. Python requests library helped in API integration and live weather details were displayed in a structured table format.
